# Flag attribution

The ten 4:3 SVGs in this directory come from **flag-icons 7.5.0** by Lipis
(https://github.com/lipis/flag-icons), used under the MIT license in `LICENSE`.
Only these ten assets are distributed; no flag CSS or icon library is loaded.
Images are requested lazily by the reader's language chips.

Flags are representative visual cues, not definitions of languages or regions.
Every chip pairs its flag with a language code and an endonym tooltip/accessibility label:

| Language | Representative flag |
| --- | --- |
| zh | CN |
| en | GB |
| es | ES |
| ar | SA |
| fr | FR |
| ja | JP |
| de | DE |
| it | IT |
| pt | PT |
| ko | KR |
