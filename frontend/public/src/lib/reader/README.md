# Reader 翻译任务前端契约

`ReaderTranslationJob` 透传后端真实进度 `completedChunks` 和 `totalChunks`。
两者须同时存在，且为非负安全整数，完成段数不得大于总段数。
为兼容旧响应和测试夹具，两者均缺省时只显示排队或运行状态。
Reader 使用十语文案展示真实的已完成段数/总段数，不从执行次数或等待时长推算进度。

正常刷新使用 sessionStorage 中的同一 jobId 发起 GET，并继续按原退避策略查询，
不重复 POST。恢复或轮询 GET 返回 404 时，无论属于跨账号、任务不存在还是已清理，
均移除无效 jobId，停止查询，返回 `TRANSLATION_JOB_NOT_FOUND` 错误。
同一正文和语言的重新提交标记只保存状态，不保留无效 jobId；
切换阅读模式或再次刷新不会自动创建任务。

Reader 保留原文并展示对应语言的提示和“重新提交翻译”按钮。
只有显式点击按钮才使用 `retry: true` 发起 POST；获得有效任务响应后移除重新提交标记，
后续刷新恢复新任务。其他 HTTP 错误保留原有状态码、错误码与任务引用。
