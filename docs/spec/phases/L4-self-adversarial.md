# L4 · 自对抗层（Self-Adversarial）

> **状态**：`DECIDED`
> **依赖**：L2（提升完成后开始）
> **阻塞**：无
> **验收**：见 §4
> **锚点**：[`02-engineering-baseline.md §5.1 L4`](../02-engineering-baseline.md)

---

## §1 目标

让系统能**证明自己在坏情况下会怎样**。

依据 **March of Nines**：从 90% 到 99.9% 的工程爬坡比 0 到 90% 更难。
本阶段把"负向控制"从零散做法变成**可执行矩阵**。

## §3 交付物

| # | 交付物 | 说明 |
|---|--------|------|
| 1 | **故障注入（E3）** | `NEWS_SENTRY_FAULT="fetch:3,d1:7"` → 第 N 次调用抛错；断言 DLQ / 重试 / 降级快照行为表 |
| 2 | **属性测试（B6）** | 300 行 **stdlib** 生成器 + 不变量（幂等 / 单调 / 守恒 / 边界）。不引入 `hypothesis` |
| 3 | **健康语义回归（A6）** | 30 天未采集的源**必须**导致 `degraded` 或 `unhealthy` |
| 4 | **状态仲裁（A7）** | 单一 `stage_to_dir(stage) -> dir` 映射函数 + 枚举↔目录双向满射测试 |
| 5 | `tools/fault_matrix.sh` | 注入 N 类故障，输出行为表 |

### 属性测试的四条不变量

| 不变量 | 含义 |
|--------|------|
| 幂等 | 同一事件重复导入不产生新行（`ON CONFLICT(event_id)` 是真正的去重兜底） |
| 单调 | 增加源或时间不减少有效事件数 |
| 守恒 | 采集数 = 新增 + 去重 + 失败 |
| 边界 | 空输入 / 超长文本 / 未来时间戳 / 非法字符不产生静默错误 |

## §4 验收命令

```bash
bash tools/fault_matrix.sh
python -m pytest tests/ -q -k "invariant or fault or health_semantics"
bash tools/falsify.sh   # 期望 A7 转 FIXED，A6 的运行时回归被证实
```

### 退出条件

| # | 条件 |
|---|------|
| 1 | 故障矩阵全部显式分类 |
| 2 | 静默错误数 = 0（每个注入故障都有日志、降级或告警之一） |
| 3 | 30 天未采集的源导致非 `ok` 健康状态（运行时验证，不再是静态判据） |
| 4 | 状态映射有单一函数，且枚举↔目录双向满射测试通过 |

---

## §5 证伪条件

| 条件 | 判定 |
|------|------|
| 任一注入故障导致**静默错误**（无日志、无降级、无告警） | **L4 失败** |
| 属性测试发现不变量被违反且无法修复 | **L4 失败**，缺口打回 L2 |

---

## §6 回滚

- 故障注入由环境变量开启，默认关闭 → 对生产零影响
- 属性测试与映射函数为纯新增
